# Portafolio Profesional de Enfermería

Este proyecto es un sitio web profesional diseñado para presentar servicios de enfermería, formación académica, atención domiciliaria y vías de contacto directo con pacientes.

## 🛠️ Tecnologías Utilizadas
- **HTML5 Semántico**: Estructuración accesible mediante `header`, `nav`, `main`, `section` y `footer`.
- **Tailwind CSS & Node.js**: Estilizado moderno, responsivo y optimizado con utility classes.
- **Formspree**: Gestión funcional de envíos en el formulario de contacto.
- **Git & GitHub**: Control de versiones documentado paso a paso.
- **Netlify**: Hosting y despliegue continuo.

## 📌 Páginas del Sitio
- `index.html`: Presentación principal (Hero, Servicios destacados y Testimonios).
- `sobre-mi.html`: Perfil profesional, filosofía de trabajo e historia.
- `servicios.html`: Detalle de prestaciones médicas, clínicas y cuidados.
- `formacion.html`: Títulos, certificaciones y capacitaciones.
- `contacto.html`: Formulario interactivo y mapa/ubicación.
